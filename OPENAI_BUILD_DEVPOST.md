# AGM for OpenAI Build

## Project Summary

AGM is an AI-assisted vehicle transport management system designed to support professional transport workflows with practical translation, OCR, voice, and operational tools.

For the OpenAI Build submission, the official demo surface is AGM Basic. Premium functionality remains under development and is excluded from the official presentation.

## Problem

Professional transport workflows need fast translation, OCR, voice assistance, and structured operational guidance without losing traceability, predictability, or a stable user experience.

## Solution

AGM Basic combines practical transport-facing tools in one stable app:

- RO / DE / EN translation
- OCR capture and local text recognition
- voice dictation and playback
- Email Assistant and text correction
- operational profile, legal notice, and cockpit flows
- Turn Command Center for controlled admin visibility

## Why It Matters

The project focuses on a stable, demonstrable baseline that can be shown clearly in a short video and judged on real usefulness, technical implementation, and user experience.

AGM is built to demonstrate that operational software can remain usable, traceable, and mobile-ready while still covering the everyday tasks that transport teams rely on.

## Demo Scope

The submission demo should show:

1. AGM Basic home screen and navigation.
2. Translator and OCR flows.
3. Voice input and playback.
4. Email Assistant and profile handling.
5. Turn Command Center and operational navigation.
6. Android packaging readiness.

## Technical Notes

- Frontend: Vite
- Backend: NestJS
- Database: PostgreSQL
- Mobile packaging: Capacitor Android
- Languages: TypeScript, HTML, CSS

## Stability Status

The presentation build is based on the validated Basic surface.

Premium remains isolated to avoid affecting the official demo and to keep the judging flow focused on the stable, validated product path.
