REGULA DE ÎNCHIDERE A MANDATELOR

PASS INTERMEDIAR ≠ MANDAT ÎNCHIS.
Root cause, patch, static PASS, build PASS, test local PASS, Pages/dev PASS și runtime intermediar PASS sunt gate-uri interne. Un mandat rămâne activ până când rezultatul este implementat, publicat, rutat în mediul final, verificat runtime, validat health/stability și demonstrat prin verdict final.

Release & Operations este responsabil de finalizarea operațională: IMPLEMENTARE → VALIDARE TEHNICĂ → RELEASE & OPERATIONS → DEPLOY/PUBLICARE → RUTARE/CUSTOM DOMAIN/CACHE/CONFIGURARE → VERIFICARE RUNTIME FINALĂ → HEALTH → STABILITY → RESTART TEST → VERDICT FINAL → MANDAT ÎNCHIS.

Blocajele tehnice remediabile fac parte din același mandat și nu creează mandate noi. Owner intervention este solicitată numai pentru decizii noi de scop, arhitectură majoră, risc major, acțiuni distructive, acces/secret imposibil de obținut autonom sau aprobări explicit owner-only.
