# APP-002 — Inventar interfețe G0

## Intrări

- text utilizator și limba țintă RO/DE/EN;
- limba sursă detectată și limba preferată;
- statusurile internet/AI/service;
- rezultat OCR sau corector, când este transferat explicit.

## Ieșiri și servicii

- API-003: `translation/actions/translate-text` și endpoint-uri health;
- istoric local al traducerii;
- clipboard prin capability port;
- APP-003 Email Assistant prin handoff controlat;
- APP-006/APP-008 furnizează capabilități lingvistice adiacente.

Textul gol nu este transmis, salvat, copiat sau transferat.
