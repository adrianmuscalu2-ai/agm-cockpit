### 1.7 RECOMANDĂRI OPERAȚIONALE SCENARIU 1

#### ✅ PRE-PLECARE (Se execută la bază, 15-20 min)

**Pasul 1: Inspecția autovehicul** (5 min)
```
1. Verific permis circulație (valabil, original)
2. Verific ITP (sticker pe parbriz, dată validă)
3. Verific asigurare RCA (certificat în vehicul)
4. Verific pneuri (profunzime, stare)
5. Verific faruri și semnalizări (pornind motorul)
6. Verific frânele (test scurt)
```

**Pasul 2: Inspecția șofer** (2 min)
```
1. Verific permis de conducere (original, valid)
2. Evaluez starea proprie (nu sunt obosit, bolnav)
3. Beau ceva, mănânc ceva ușor dacă e nevoie
```

**Pasul 3: Tahograf** (3 min)
```
1. Pornesc motorul
2. Tahograful trebuie să pornească automat
3. Butonul START → Înregistrare "conducere"
4. Verific pe ecran: ora, km, tip activitate = conducere
```

**Pasul 4: Documente transport** (3 min)
```
1. CMR → Verific: expeditor, destinatar, marfă, greutate
2. Facturi → Copii la bord
3. Documente marfă → Pus în ordine
4. Documente vamă → NU necesare pentru local
```

**Pasul 5: Marfă** (3-5 min)
```
1. Verific dacă marfă este fixată corespunzător
2. Verific dacă coincide cu CMR (cantitate, descriere)
3. Verific dacă nu depășesc greutate legală
```

**Pasul 6: Rută** (2 min)
```
1. Verific pe hartă/GPS: ruta, distanță, timp
2. Calculez: ore conducere necesare
3. Calculez: pauze obligatorii în cale
4. Planific: unde fac pauza de 45 min
```

#### ✅ ÎN DRUM (Se monitorizează pe parcurs)

**Conducere**
```
- Respectez viteza maximă
- Conduc responsabil
- Fac pauza obligatorie după 4.5h conducere (45 min)
- Verific tahograf periodic (afișare corectă)
```

**Control întâmpinat**
```
- Opresc autovehiculul controlat
- Prezint documente: permis, ITP, RCA, CMR
- Comportament civil și cooperativ
- Nu contest pe loc, contest după
```

#### ✅ SOSIRE ȘI ÎNTOARCERE

**La destinație**
```
1. Verific odometrul (km parcurși)
2. Verific tahografi (ore înregistrate)
3. Obțin semnătura primitor marfă
4. Completez CMR cu ora sosire
```

**Înainte de întoarcere**
```
1. Verific tahograf: restul orelor disponibile pentru zi
2. Dacă ≥ 4.5h disponibile → Pot pleca imediat
3. Dacă < 4.5h disponibile → Fac pauza/odihnă înainte
4. Inițiez din nou tahografi cu START
```

**Sosire la bază**
```
1. Completez tahografi: "Alte activități" (parcare)
2. Scoatem cartele tahograf
3. Documentez: km, ore, odihnă, incident
4. Raportez orice problemă (defecțiune, control, etc.)
```

